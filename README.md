# MarbleRun
A custom 3D-printed marble run designed in Onshape for Hack Club's Half-Life project. Features include a Plinko track, staircase track, curved tracks, and a funnel. This project explores CAD modelling, sketching, extrusion, revolve, and fillet tools while focusing on precise measurements, functional design, and learning through experimentation.

I designed the individual parts separately and then brought them together in an assembly. Throughout this project, I have been learning how to use CAD tools, create different shapes, adjust dimensions, and solve problems to make the components fit together properly.

Features

- Curved Track: Creates a winding path for the marble to travel through.
- Funnel: Guides the marble toward its exit and into the next section.
- Staircase Track: Adds a stepped section to the marble's path.
- Plinko Track: Uses obstacles to change the marble's direction.
- Modular Design: Uses multiple components that fit together to form one marble run.
- Custom CAD Models: Each component is designed and adjusted to fit the overall assembly.

Assembly and Connections

After creating the individual components, I started assembling them in Onshape. I used assembly tools, including Fastened Mates, to position and connect the parts.

During assembly, I discovered that some of my components did not fit together properly. Some parts overlapped, while others needed changes to their lengths, widths, or shapes. I went back and edited several parts to improve their fit and alignment.

I am also working on improving the connections between track sections so that the parts can be assembled securely, especially when preparing them for 3D printing.

Design Process

I began by learning the basics of Onshape, since I was new to CAD modelling. I practised creating 2D sketches and using features such as Extrude, Revolve, Fillet, and other tools to build my components.

Once the individual parts were designed, I moved on to assembling them. This stage helped me understand that designing a part on its own is different from making sure it works with the other parts in a complete assembly.

I had to return to some of my original designs, change their dimensions, and modify certain components to improve how everything fit together.

Challenges and What I Learned

One of the main challenges was learning how to use Onshape while designing a project with multiple connected parts. I also learned that parts that look correct individually may still have problems when assembled.

Some of the challenges I worked on included:

- Learning new CAD tools and features.
- Creating curved tracks and other custom shapes.
- Using Fastened Mates to position components in an assembly.
- Identifying overlapping parts and alignment problems.
- Editing dimensions and redesigning parts to improve their fit.
- Planning how separate components will connect.
- Understanding the importance of designing parts with assembly and manufacturing in mind.

This process taught me that CAD design involves more than just creating shapes. It also requires testing how parts fit together, identifying problems, and making improvements.
